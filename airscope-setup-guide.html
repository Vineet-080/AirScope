Step-by-Step Setup
1
Extract the backend
Unzip the backend package you downloaded. Open a terminal inside the folder.
bash copy
# Unzip (or use your file manager)
unzip airscope-backend.zip
cd airscope-backend
2
Create a Python virtual environment
Keeps your project dependencies isolated. Works on Windows, Mac and Linux.
bash — Mac / Linux copy
python3 -m venv venv
source venv/bin/activate
bash — Windows (PowerShell) copy
python -m venv venv
venv\Scripts\Activate.ps1
You'll see (venv) appear at the start of your terminal prompt — that means it worked.
3
Install all dependencies
This installs FastAPI, SQLAlchemy, scikit-learn, httpx, and all other packages listed in requirements.txt.
bash copy
pip install -r requirements.txt
Takes 1–3 minutes on first run — scikit-learn and numpy are large. Subsequent runs are instant.
4
Configure environment variables
Copy the example file and fill in your values. At minimum, only SECRET_KEY is required — everything else has safe defaults.
bash copy
# Mac / Linux
cp .env.example .env

# Windows
copy .env.example .env
.env — edit this file copy
# ── API Keys ────────────────────────────────────────────
# Leave as "demo" to use mock data (no account needed)
# Or add real keys for live AQI + weather
OPENWEATHER_API_KEY=demo
WAQI_API_KEY=demo

# ── REQUIRED: change this to any long random string ──
SECRET_KEY=my-super-secret-airscope-key-change-this-in-production

# ── Database (SQLite is zero-config, no install needed) ──
DATABASE_URL=sqlite+aiosqlite:///./airscope.db

# ── App ──────────────────────────────────────────────────
APP_ENV=development
ALLOWED_ORIGINS=http://localhost:3000,http://localhost:5500,http://127.0.0.1:5500,null
ALLOWED_ORIGINS — the value null is needed when opening the HTML file directly from your filesystem (file://). If you serve it via VS Code Live Server (port 5500) or similar, include that origin too.
4b
Get free API keys (optional — skip for demo mode)
Both services have free tiers that cover normal usage. Takes about 2 minutes each.
ServiceFree tierURLKey name in .env
WAQI 1,000 req/day aqicn.org/data-platform/token WAQI_API_KEY
OpenWeatherMap 1,000 req/day openweathermap.org/api OPENWEATHER_API_KEY
WAQI key — Click the link, enter your email, and your token arrives instantly.
OpenWeatherMap — Create a free account, go to "API keys" in your profile, and copy the default key. It activates within 10 minutes of account creation.
5
Start the backend server
This creates the SQLite database automatically on first run (no setup required), trains the forecast ML model, and starts the scheduler that refreshes AQI data every 15 minutes.
bash — from inside the airscope-backend folder copy
python -m app.main
You should see:
🚀 AirScope API starting up…
✅ Database initialised
[Forecast] Model trained on synthetic data.
[Scheduler] Started — AQI refresh every 15 minutes
INFO: Uvicorn running on http://0.0.0.0:8000
Alternative: with auto-reload (development) copy
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000

Verify the backend is running
Open these URLs in your browser to confirm everything is working.

7
Open the connected frontend
Open airscope-connected.html directly in your browser. The frontend will automatically connect to the backend at localhost:8000 and load live data.
Quickest method — Double-click airscope-connected.html in your file manager. It opens at a file:// path which works fine.
Better method — Use VS Code with the Live Server extension (right-click → "Open with Live Server"). This gives you http://localhost:5500 and hot-reload on save. Make sure http://localhost:5500 is in ALLOWED_ORIGINS in your .env.
The frontend connects to the API via this line at the top of the script block. Change it if your backend runs on a different host/port:
airscope-connected.html — line ~1244 copy
const API_BASE = 'http://localhost:8000';
8
Register your first account
Click Register in the top-right of the frontend. This creates a user in the SQLite database. After registering, plans, locations and settings are all synced to your account.
Or register directly via the API
curl -X POST http://localhost:8000/api/auth/register \
  -H "Content-Type: application/json" \
  -d '{
    "email": "you@example.com",
    "username": "yourname",
    "password": "password123",
    "full_name": "Your Name"
  }'
What gets stored in the database (airscope.db):
• User account + bcrypt-hashed password
• Health profile (asthma, athlete mode, etc.)
• Saved locations (Home, Office, etc.)
• Plans with AQI forecast snapshots at time of creation
• AQI historical readings (refreshed every 15 min by scheduler)
Database Details
DB
Inspecting the SQLite database
The database file airscope.db is created in the backend folder on first run. You can inspect it with any SQLite tool.
Install DB Browser for SQLite (GUI — recommended)
# Mac
brew install --cask db-browser-for-sqlite

# Windows — download from
# https://sqlitebrowser.org/dl/

# Ubuntu / Debian
sudo apt install sqlitebrowser
Or use the command line
# Open the database
sqlite3 airscope.db

# View all tables
.tables

# See table structure
.schema users

# Query users
SELECT id, email, username, created_at FROM users;

# Query plans
SELECT title, activity_type, scheduled_at, risk_level FROM plans;

# Query AQI history
SELECT city, aqi, pm25, recorded_at FROM aqi_cache ORDER BY recorded_at DESC LIMIT 20;

# Exit
.quit

PG
Upgrading to PostgreSQL (production)
SQLite is perfect for development and single-user deployments. Switch to PostgreSQL for multi-user production use.
1. Install PostgreSQL and create the database
# Mac
brew install postgresql@16
brew services start postgresql@16
createdb airscope_db

# Ubuntu / Debian
sudo apt install postgresql
sudo -u postgres createdb airscope_db
sudo -u postgres psql -c "CREATE USER airscope WITH PASSWORD 'yourpassword';"
sudo -u postgres psql -c "GRANT ALL PRIVILEGES ON DATABASE airscope_db TO airscope;"
2. Install the async PostgreSQL driver
pip install asyncpg psycopg2-binary
3. Update DATABASE_URL in .env
# Replace the SQLite line with:
DATABASE_URL=postgresql+asyncpg://airscope:yourpassword@localhost:5432/airscope_db
4. Restart the backend — tables are created automatically
python -m app.main
That's it. SQLAlchemy handles the rest — all queries, schemas and relationships work identically with PostgreSQL.
Troubleshooting
!
Common issues & fixes
❌ CORS error in browser console
Add your frontend's origin to ALLOWED_ORIGINS in .env.
Common values: http://localhost:5500, http://127.0.0.1:5500, null (for file://).
Restart the backend after changing .env.
❌ "Cannot reach backend" in the UI
Check that the backend is running (python -m app.main).
Confirm API_BASE in airscope-connected.html matches the backend URL.
Default: http://localhost:8000
❌ OpenWeatherMap returns 401
New OWM keys take up to 10 minutes to activate after account creation.
Leave OPENWEATHER_API_KEY=demo for now and swap in the key after activation.
❌ Plans require sign-in
This is by design — plans are stored per-user in the database.
Click "Sign In / Register" in the Planner section or the top-right nav button.
❌ Port 8000 already in use
Change the port: uvicorn app.main:app --port 8001
Then update API_BASE in the frontend to http://localhost:8001.
Production Deployment Checklist
  • Replace SECRET_KEY in .env with a 64-character random string
  • Add real WAQI_API_KEY and OPENWEATHER_API_KEY
  • Switch DATABASE_URL to PostgreSQL
  • Set ALLOWED_ORIGINS to your actual frontend domain only
  • Set APP_ENV=production
  • Run behind NGINX as a reverse proxy
  • Add HTTPS/TLS certificate (Let's Encrypt)
  • Set up process manager: pm2 or systemd
  • Replace in-memory cache with Redis (aioredis) for multi-worker deployments
  • Set up database backups (automated daily dumps)
